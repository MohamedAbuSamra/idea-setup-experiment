# features/

| Folder | What it holds |
| --- | --- |
| `shell/` | Demo chrome: sidebar, epic chips, progress, demo controls, phone pair, browser frame |
| `mobile/signup/` | New idea journey (placeholder "Petal" app) |
| `mobile/signup-current/` | Current journey, shown on the left phone via `compareFlow` |
| `mobile/shared/` | Placeholder phone app styles shared by both journeys |
| `website/dashboard-setup/` | Desktop epic (placeholder "Petal Studio") |

Mobile epics with `compareFlow` show two phones. Epic `demoControls` decide which sidebar demo lines appear (`autoplay`, `speed`, `scenario`).
